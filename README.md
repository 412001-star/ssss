# ssss

此為一個純前端的背單字示範應用，使用 HTML / CSS / JS (無框架)。

功能：
- 中央顯示單字卡，點擊卡片可翻面查看中文、詞性、例句及字根分析。
- 管理頁面可新增、刪除單字。
- 管理頁面的「自動填入」按鈕會呼叫公開 API 嘗試填入中文翻譯、詞性與字根來源。

快速啟動：
1. 開啟 `index.html`（直接在瀏覽器開啟即可）。
2. 在「管理」頁面新增單字，或使用預設兩筆範例。

注意事項：
- 自動填入會使用公開第三方 API（dictionaryapi.dev、api.mymemory.translated.net），因 CORS 或服務可用性可能失敗。
- 所有資料儲存在瀏覽器 `localStorage`，不會上傳到伺服器。
